# Love App - Screenshot Generation Guide

## Required Screenshots for Google Play

### Specifications

**Phone Screenshots:**
- Format: PNG
- Orientation: Portrait (vertical)
- Resolution: 1080x1920 pixels
- Minimum: 2 screenshots
- Maximum: 8 screenshots
- Language: English (can have multiple language versions)

**Tablet Screenshots:**
- Format: PNG
- Orientation: Landscape (horizontal)
- Resolution: 2560x1600 pixels
- Optional but recommended

- App logo or welcome message

**Screen 4: Messaging**

- Message bubbles

**Screen 5: Safety Features**

- Verification process
- Headline: "Stay Safe"

**Screen 6: Events (Optional)**
- Date planning interface

- Headline: "Plan Dates Together"

### Design Tips

1. **Consistency:**

2. **Text Overlay:**
   - Use bold, readable fonts
   - White text on gradient background
   - Max 2-3 lines per screenshot
   - Highlight key features

3. **Real Content:**
   - Show actual app interfaces
   - Use realistic profile examples
   - Display real chat messages
   - Show actual UI elements

4. **Engagement:**
   - Show emotional connections
   - Highlight safety features
   - Demonstrate ease of use
   - Show success stories

### Process

1. **Create in Figma/XD**
   - Design 6-8 screenshots
   - Use app UI as base
   - Add text overlays
   - Keep consistent branding

2. **Export**
   - Export as PNG
   - Ensure 1080x1920 resolution
   - Name clearly: screenshot-1.png, etc.

3. **Upload to Google Play**
   - Go to Store Listing → Screenshots
   - Upload phone screenshots
   - Set language (English)
   - Upload in order

4. **Review**
   - Check preview
   - Ensure quality
   - Verify text is readable
   - Test on different devices

### Upload Instructions

1. Open Google Play Console
2. Go to Your App → Store Listing
3. Scroll to Screenshots section
4. Click "Add screenshot"
5. Select Phone (1080x1920)
6. Upload PNG file
7. Repeat for all 6 screenshots
8. Save changes

### Pro Tips

- **A/B Test:** Different screenshots perform differently
- **Localize:** Translate text for different regions
- **Update:** Refresh screenshots quarterly
- **Mobile-First:** Optimize for mobile viewing
- **Call-to-Action:** Highlight key actions
- **Social Proof:** Show testimonials or ratings
- **Feature Showcase:** Focus on unique features
- **Brand Consistency:** Match app design exactly

### Optimization

- Keep file sizes under 10MB
- Use PNG format (better quality)
- Ensure high contrast for readability
- Test text at actual store preview size
- Include all major features
- Show user-generated content (with permission)
- Demonstrate safety features
